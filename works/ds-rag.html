S배경 — 상용 멀티문서 QA의 3중 제약

사내 문서로 QA 서비스를 만들면 정보가 여러 문서에 파편화돼 있어 대부분의 질문이 멀티문서 질문이 됩니다. 상용 서비스는 여기서 세 가지를 동시에 요구합니다 — ① 답에 필요한 컨텍스트를 누락 없이 검색할 것, ② 상용 LLM API의 토큰 비용을 최소화할 것, ③ 소규모 인프라로 감당 가능하게 운영 오버헤드를 낮출 것. 청크를 많이 가져오면 ①은 풀리지만 ②가 무너지고, 무거운 그래프 인프라를 쓰면 ③이 무너집니다.

질문 분해(QD)가 표준 해법이지만, LLM 분해는 질문의 핵심 엔티티를 빠뜨리거나 없던 내용을 만들어 검색을 오히려 망가뜨립니다. DS-RAG는 이 지점을 두 모듈로 풉니다 — 질문을 훼손하지 않는 분해(EPQD)와, top-K 고정 대신 질문 구조에 맞춰 입력 컨텍스트를 동적으로 고르는 선택기(DICS).

A설계와 구현

01기존 분해의 실패를 먼저 규명했다

  • 가장 널리 쓰이는 LangChain QD를 케이스 스터디로 분석해 세 가지 실패 유형을 규명 — ① 불필요한 서브질문 과잉 생성, ② 핵심 정보 누락, ③ 원 질문에 없던 내용으로 변형
  • 분해 품질을 잴 지표가 없어 EAR(엔티티 추가율)·EOR(엔티티 누락율)을 직접 정의 — 검색 결과가 아니라 분해 자체를 측정

02EPQD — 의미를 보존하는 분해

원 질문 → 접속사·쉼표 기준 의미 분할 (따옴표 예외) → 각 phrase + 원문 동반 프롬프트 → phrase당 서브질문 1개
  • 멀티문서 질문은 비교 대상들이 접속사·쉼표로 나뉘는 언어적 특성이 있음 — LLM에게 분해를 통째로 맡기지 않고, 결정적 규칙으로 먼저 의미 단위를 분할
  • 각 분할 조각을 원문 전체와 함께 LLM에 넣어 서브질문을 생성 — 조각만 보내면 맥락을 잃고, 원문만 보내면 변형되므로. 원문 용어 보존·문법적 완결성·조각당 1개 생성을 프롬프트 원칙으로 강제
  • 결과: 복잡 질문에서 엔티티 누락률 70.2% → 7.4%, 불필요 엔티티 추가율 47.3% → 14.4% (LangChain QD 대비, 자체 정의 EAR/EOR 지표)

03기존 데이터셋으로는 실험이 성립하지 않았다

  • HotpotQA는 질문이 단순하고 정답 청크가 최대 2개뿐이며, 정답 청크 없이도 LLM이 답을 맞혀버리는 사례가 있어 프레임워크 검증 자체가 불가능 — Multi-hop RAG도 중복 서술 문제로 부적합
  • 그래서 정답 청크 2~4개가 반드시 필요하고, 정답이 문서에 명시돼 있지 않아 LLM이 추론해야만 하는 멀티문서 QA 데이터셋 4,000문항(ranking/comparison 유형)을 GPT-4o 기반으로 직접 구축 — GitHub에 공개

04벤치마크 실험 — 프레임워크 전체 검증

  • NonQD-리랭킹 / EPQD+리랭킹(서브질문·원질문 기준) 3종 벤치마크를 구축하고 Precision·Recall·F1, 평균 청크 수(비용), ANLS(답변 품질)로 평가
  • DICS(팀 설계: 질문 그래프 Core 노드 기반 선택 기준 + GAT 그래프 임베딩 선택 모델)와 결합한 DS-RAG가 입력 청크를 절반 이하로 줄이면서 F1을 0.596 → 0.877로 끌어올림을 검증 — 선택 모델은 상용 리랭커 대비 파라미터 30% 수준(운영 오버헤드 ↓)

R결과

  • 입력 컨텍스트 F1 0.877 — EPQD+리랭킹(0.596) 대비 +28.1%p, 분해 없는 리랭킹(0.14)과는 비교 불가 수준
  • 같은 정확도 구간에서 LLM 입력 청크 8.6 → 4.0개(절반 이하) — 상용 API 비용 제약을 직접 해소

W설계 선택의 이유

규칙 분할 + LLM 생성분해를 LLM에 통째로 맡기면 질문이 변형됨 — 결정적 규칙(접속사·쉼표)이 구조를 잡고, LLM은 조각을 완성하는 역할로 좁힘
EAR·EOR 자체 지표검색 F1로는 "분해가 무엇을 훼손했는지"를 못 잼 — 원 질문과 서브질문의 엔티티 집합을 직접 비교하는 지표를 정의
데이터셋 자체 구축기존 셋은 정답 청크가 적고 유출이 있어 프레임워크의 차이가 지표에 안 드러남 — 검증이 성립하는 조건을 데이터부터 설계
GPT-4o 고정분해 방식 간 비교에서 모델 변수를 제거해 재현성 확보
